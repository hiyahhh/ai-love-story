# 对话种子：三生三世与你相约

状态：候选创意，未获定稿；无真实新人资料。以下是本项目改编构想，非原片复述。

导演命题：相同的照顾动作跨越三世，从一人付出，到对方回应，最后成为并肩生活。

- 第一世：江南雨桥，一人为另一人偏伞，自己淋湿肩头。借《青蛇》的借伞与雨中靠近机制。
- 第二世：旧城或车站，对方主动回头或奔向等候的人，回应前一世的照顾。借《花样年华》的距离、遮挡和停顿；若设民国，明确这是新设定，原片是1960年代香港。
- 第三世：回到今生，重现真实初遇或虚构样片中明确设定的初遇，最终两人一起撑正伞。借《傲慢与偏见》的走近与《时空恋旅人》的共同面对风雨。

可选连接：同构回头、伞、红绳或声音。不要把所有母题都塞进同一部短片。《你的名字。》可研究结绳与跨时空联系，《神话》可研究梦境与重逢，《剑雨》可研究石桥与等待。它们是研究候选，不是必须采用的片单。

前序对话给出的偏伞、道具转换、三世结构及片尾旁白都是原创提案，不能误记为电影真实镜头或新人经历。此前所有独立片段的 00:00 链接只是整段入口；后续请求精确时间码时必须重新观看核验。
