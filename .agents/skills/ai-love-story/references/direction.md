# Directing and continuity

## Emotional engine

Give the lead a goal, a specific obstacle, a tactic and a visible change. A romantic beat should alter the relationship: strangers → curious → choosing each other. A glance needs a reason and an answering reaction. Let the ending pay off a prop, gesture or sound from the beginning.

For promotional samples, invent the story openly. Three useful directions:

- An everyday encounter becomes a wedding ritual: grounded, economical, easy to personalize.
- The same two people find each other across eras: strong visual range, more wardrobe/location references and continuity work.
- A playful missed connection ends in a reunion: clear goal/obstacle, but simplify crowd action and complicated physical contact.

Use one direction per short unless the brief calls for a montage. Avoid copying the tutorial's characters, exact prompts or plot as if they were original client work.

## Shared technical block

Fix aspect ratio, photoreal/stylized treatment, grain, palette, key light, camera movement and audio strategy for a sequence. Lens language must support the framing rather than contradict it. Use readable medium/close framings for identity-critical shots and avoid rapidly rotating faces in the first test.

## Continuity ledger

Track per cut: character reference/version, outfit, hair, screen position and travel direction, gaze target, prop position and owning hand, location orientation, light direction, start pose and exit pose. A match cut requires matching composition as well as a related subject.

## Troubleshooting

| Failure | First response |
| --- | --- |
| Faces drift | Inspect reference quality; use a closer, simpler shot; reduce rotation and movement. |
| Wardrobe or prop changes | Use accepted wardrobe/prop references and explicit states; remove conflicting descriptions. |
| Impossible hands/contact | Separate actions, reduce hands in frame, or cut around contact. |
| Geography flips | Establish the axis and fixed landmarks; add a spatial storyboard. |
| Emotion feels posed | Replace an abstract adjective with an acting task and a small visible reaction. |
| Timing or cuts ignored | Split into shorter generations and enforce timing in the edit. |
| Overloaded scene | Keep the essential story beat; generate its components separately. |
| Background warps | Reduce crowd complexity/camera travel; test a simpler composition. |

These are diagnosis starting points, not guaranteed fixes. Inspect each actual output.
