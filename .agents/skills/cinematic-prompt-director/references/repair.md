# Repair a failed shot

1. Inspect available clip/frames and source prompt. Identify generation, editing or playback symptoms. If no media is supplied, label diagnosis provisional.
2. Compare with accepted references, first frame, geography, camera and settings. Preserve successful sections.
3. Choose one likely cause and a small targeted change. Distinguish observation from hypothesis.
4. Return the revised prompt, change and acceptance check. For final-only requests return just the prompt.
5. Run another generation only when requested, supported and within authorization/budget; inspect it before claiming success. Log failed attempts too.

| Symptom | Candidate repair | Acceptance check |
| --- | --- | --- |
| Face drifts during turn | Better reference binding, less rotation, closer framing | Identity holds throughout movement |
| Left/right flip | Physical camera side, stable landmark, clear opening state | Same world order across cuts |
| Wrong angle | Height/side/distance/aim instead of angle adjective | Intended surfaces visible |
| Posed acting | Task and one motivated reaction | Readable thought/action change |
| Fused hands/floating contact | Separate actions, clarify supports, simplify | Valid contact and release |
| Timing/cuts ignored | Split generation, enforce edit timing | Coherent boundaries and timeline |
| Device disappears | Make it primary; specify trigger/landing | Visible technique with stable geography |
| Action smears | Reduce choreography/camera conflict, readable holds | Clear cause, contact and recovery |
| Playback judder | Inspect file timing/export | Correct target playback |

Repeated failures warrant changing references, shot design or target suitability. More detail and unchanged retries are not universal fixes.
